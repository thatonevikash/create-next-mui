Scaffold your `nextjs` + `mui` project blazingly fast ⚡.

## Overview

`create-next-mui` supports the following:

- ⚡ Next.js App Router
- 🎨 Material UI
- 📦 `TypeScript` or `JavaScript` templates
- 🪝 `Zustand` and `React Query ( TanStack Query )` extending support
- 🧹 `ESLint` Flat Config
- 📁 Scalable project structure

> No global installation required.
