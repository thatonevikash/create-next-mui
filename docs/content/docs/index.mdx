## Overview

`create-next-mui` supports the following:

- ⚡ [Next.js<ArrowUpRight className="inline-flex h-4 w-4" />](https://nextjs.org/) App Router
- 🎨 [Material UI<ArrowUpRight className="inline-flex h-4 w-4" />](https://mui.com/material-ui/getting-started/)
- 📦 `TypeScript` or `JavaScript` templates
- 🪝 [`Zustand`](https://zustand.docs.pmnd.rs/learn/getting-started/introduction) and [`TanStack Query`](https://tanstack.com/query/latest/docs/framework/react/installation) extending support
- 🧹 `ESLint` flat config
- 📁 Scalable project structure

> No global installation required.
