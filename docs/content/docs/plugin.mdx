Now, `next-mui` supports plugins to advance the setup.

## Supported `flags`

| Signature | Shorthand | Description                                                                        |
| :-------- | :-------- | :--------------------------------------------------------------------------------- |
| `--yes`   | `-y`      | Skips the interactive `CLI` completely and setup application with default template |
| `--js`    |           | Skips template selection                                                           |
